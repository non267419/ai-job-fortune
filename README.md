# AIお仕事占いメーカー

放課後等デイサービスのPC活動向けの、GitHub Pagesだけで動く一時保存型Webアプリです。

## 方針

- Google Apps Scriptは使いません
- スプレッドシートは使いません
- DBやログインは使いません
- 占いデータはブラウザの `sessionStorage` にだけ置きます
- 60分で自動的に消えます
- 友達には共有コードで渡します

## ファイル

- `index.html`
- `styles.css`
- `app.js`
- `design.md`
